# NEXORA Orb variants

The active OrbEngine now dispatches to the original three canvas renderers copied from `nexora-orb-test.html`: `drawOld` (NEXORA (old) / particle sphere), `drawNeural` (Neural Sphere), and `drawFlow` (Particle Flow). The previous generic profile-colored orb rendering is no longer used. Selector values are `nexora`, `nexo`, and `nexie`; selection persistence and the existing SFX controls are retained.
