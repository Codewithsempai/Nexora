# NEXORA Three Original Orb Identities

Phase 1 contains three original, distinct orb identities. They are not color-only skins:

- **NEXORA — The Core:** round particle sphere, luminous amber-white core, gentle breathing, balanced orbital ellipses.
- **NEXO — The Pulse:** cyan flowing/ribbon-like projection, twist-wave motion, elongated orbital path, faster reactive character.
- **NEXIE — The Spirit:** violet constellation-like organic particle cluster, breathing lobe motion, spiral-style orbital path.

The orb selector persists the choice. Selection triggers an identity-specific synthesized chime through the existing SoundSystem master output and respects the global SFX toggle. State modes (Idle, Listen, Think, Speak, Wake, Error, Offline) continue to modulate each identity.

These are separate renderer behaviors/profile shapes, not merely palette changes.
