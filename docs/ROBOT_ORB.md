# NEXORA Robot Orb (v0.3.14)

The 3D Nexora robot is now a fourth Orb identity, next to NEXORA / NEXO / NEXIE.

**Select it:** Orb panel → *Orb Studio* → preset **NEXORA Robot — 3D Robot** (main Orb), or *Popup Orb Studio* → Preset (floating wake Orb). When the robot is selected a **Robot Studio** section appears in the Orb panel.

## Orb states → robot
| Orb state | body animation | face |
|---|---|---|
| Idle | breathing, weight shifts, wandering eyes | calm, blinks, saccades |
| Listen | head turns, leans in, ears perk | raised brows, green, mic bars + ripple driven by mic level |
| Think | head tilt, finger tapping | squint, violet orb, typing dots + orbiting dots |
| Speak | gestures scaled by voice | **lip sync from the Orb's real voice level** (synthetic mouth if no level), voice wave |
| Wake | body boots, head lifts | screen boot line |
| Error | head shake, red glitch | angry face, red, warning triangle, glitch bursts |
| Offline | slumps, screen fades | screen off, orb dimmed |

## Robot Studio
* **View** auto / full / bust / face (auto picks by Orb size, so the 30 / 84 px Orbs show the face), "body acts the emotion".
* **Robot paint** — default **Nexora Black** (graphite, as in the Animation Lab) plus 6 colourways (the FBX has no embedded textures, so the robot is painted by material name).
* **Expressions (22)** — 8 emotions (neutral, happy, sad, angry, fear, surprise, disgust, contempt) + 14 characters: love, dizzy, starstruck, cool, knocked-out, sleepy, confused, crying, shy, mischief, joy, rage, shock, smug. Held until **Auto**.
* **Facial actions (26 + timed)** — wink, blink, gasp, sigh, yawn, eyeroll, raisebrow, bitelip, stare play once; smile, grin, beam, smirk, sneer, frown, pout, grimace, wince, purse, clench, squint, glare, glower, furrow, teary, deadpan, blush, flush, pale are held.
* **Eye styles** — heart, X, spiral, star, sleep, shades.
* **Emote FX (10)** — hearts, sparkles, zzz, question, exclaim, sweat, rain, music, anger mark, dizzy stars.
* **Face screen VFX (12)** — scanlines, scan beam, LED dot matrix, flicker, vignette, chroma split, static noise, bloom pulse, emote FX, status FX, blink, eyes-follow-head; one-shots **Boot / Glitch / Screen off / Screen on**; glow + expression-strength sliders; face colour (or follow state colour).
* **Body animations (14)** — idle listening thinking speaking greeting happy confused sad surprised sleep wakeup goodbye error offline.

Options are remembered (`localStorage: nexora-robot-opts-v2`); a held expression is session-only.

## Files
| path | purpose |
|---|---|
| `src/renderer/orb/robot-orb.js` | robot Orb renderer (three.js → off-screen WebGL → Orb canvas), state mapping, camera, paint (no glass sphere — the robot stands on its own) |
| `src/renderer/orb/robot-studio.js` | Robot Studio UI (built from the tables below) |
| `src/renderer/robot/nexora-animator.js` | 14 body states (from robot pack v3) |
| `src/renderer/robot/nexora-face.js` | face engine (v3 + new `setEyeStyle`) |
| `src/renderer/robot/nexora-face-vfx.js` | **new** expression pack, emote FX, screen VFX, status FX |
| `src/renderer/robot/nexora-voice-sync.js` | lip sync (v3 + new `feed(level)` for the app's own voice level) |
| `src/renderer/robot/robot-fbx.js` | the robot model as base64 (generated by `node tools/build-robot-asset.js`) |

| `assets/robot/` | original FBX, robot pack README and preview images |

The robot is loaded lazily — nothing is downloaded or parsed unless the Robot Orb is selected.
CSP change: `img-src` now also allows `blob:` (FBX texture loader). Tests: `node tests/unit/robot-test.js`.

## Popup note (v0.3.14b)
The popup window is created hidden, where `requestAnimationFrame` is paused, so the robot used to start loading only after the popup was shown. It now starts loading as soon as the popup receives the `robot` profile, falls back to the NEXORA orb if WebGL fails, recovers from a lost WebGL context, and is sized to match the chosen popup size.

## Popup robot (v0.3.14c)
* (v0.3.14d replaces the fixed x1.5 size and the face halo below: the halo behind the head is **removed**, and the size now follows the monitor, see next section.)
* **Bigger:** the popup robot no longer sits inside the round-orb padding (it was drawn at 68% of a canvas that was already 68% of the window). Its canvas now equals the window and the camera frames the full body tightly. The popup size setting is the robot's height x 1.5 (Default 200 -> 300 px, Big 300 -> 450 px; limited to the screen's work area).
* **Pure black + glow:** body paint *Nexora Black* is now `#000000` with a glossy sheen from cool rim lights and very low ambient light; the face is a bright white glowing screen (glow 1.7) with a soft halo behind the head. Listen / Think / Error / Offline still use their state colours. Face colour and Glow are still adjustable in Robot Studio.
* Files: `src/main/application/popup-window.js` (geometry), `src/renderer/orb/robot-orb.js` (lights, paint, framing, halo), `src/renderer/orb/orb-engine.js`.

## Popup size per monitor (v0.3.14d)
The popup is placed on the monitor where the mouse pointer is, and sized from that monitor's usable height (taskbar excluded, in DIPs, so Windows scaling is already applied). Robot height = 28% of the work-area height (kept between 200 and 400 px) x (size setting / 200). Round orbs scale by work height / 1040 (0.75 to 1.3). It never exceeds 85% of the work height or 50% of the width, and re-fits when a monitor is added, removed or its resolution/scaling changes.

| screen (work area, DIP) | Default 200 | Big 300 | Small 132 | Tiny 84 |
|---|---|---|---|---|
| laptop 1366x768 (728 high) | 204 | 306 | 135 | 90 |
| laptop 1920x1080 @125% (824) | 231 | 347 | 152 | 97 |
| 1080p monitor (1040) | 291 | 437 | 192 | 122 |
| 1440p / 4K @150% (1400) | 392 | 588 | 259 | 165 |
